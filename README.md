# FFmpeg Encoder Queue

![Version](https://img.shields.io/badge/version-0.5.5-blue) ![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)

Настольное приложение Windows для **пакетной обработки видео и аудио** через FFmpeg. Стабильная версия — **0.5.5**. Мобильная версия для Android — **FF Mobile 1.2.0**.

## Возможности

- Очередь задач с индивидуальными настройками для каждого файла
- Обрезка и вырезание фрагментов, кроп видео по четырём сторонам
- Микшер аудиодорожек с регулировкой громкости и предпрослушиванием
- Скачивание видео из сети (yt-dlp) с постановкой в очередь
- CPU- и GPU-кодирование (NVENC, H.264/H.265)
- Внешние аудиодорожки, импорт MTS, проверка PGS/MP4 перед запуском
- Профили настроек: «Настройки ко всем» с сохранением ручных параметров
